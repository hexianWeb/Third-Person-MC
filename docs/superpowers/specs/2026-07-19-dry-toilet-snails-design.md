# 旱厕与蜗牛交互功能设计

## 目标

在 `disgust` 分支中将 `public/models/cesuo.glb` 作为固定地标放置到体素世界 X/Z 原点。旱厕底座自动等比适配 2×2 方块平台并贴合地表；旱厕周围生成 12 只小型体素蜗牛。玩家在近距离用屏幕中心准星左键点击蜗牛后，蜗牛缩进壳内，并在约 3 秒后恢复爬行。

## 范围

本功能仅涉及 Three.js 世界层、资源声明、输入仲裁和相关测试。它不增加或修改 Vue UI、HUD、准星样式、物品、成就、音效、旱厕碰撞或旱厕破坏功能。

## 架构

功能拆分为三个职责明确的单元：

- `DryToiletLandmark`：等待原点地形可用，整理 2×2 平台，克隆并适配旱厕模型，暴露地标就绪状态和活动中心。
- `SnailManager`：在地标就绪后确定性生成 12 只蜗牛，更新蜗牛、执行准星射线点击检测，并拥有共享的蜗牛渲染资源。
- `VoxelSnail`：封装单只蜗牛的部件层级、游走、贴地、避障以及正常、缩入、保持、展开状态。

`World` 在地形和玩家创建后初始化地标与蜗牛管理器，在每帧更新中驱动二者，并在世界销毁时依次清理。旱厕资源仍由现有 `Resources` 系统统一加载，所有跨层输入继续使用现有 mitt 事件总线。

## 资源和模型适配

在 `src/js/sources.js` 中以 `gltfModel` 类型声明 `models/cesuo.glb`。运行时从资源的 `scene` 克隆旱厕模型，开启适用网格的投射与接收阴影。

模型适配不得依赖当前文件的硬编码尺寸。组件使用 `THREE.Box3` 计算克隆模型的世界包围盒，并据此完成以下变换：

1. 取 X/Z 尺寸的较大值，将模型等比缩放到正好 2 个世界方块。
2. 缩放后重新计算包围盒，把 X/Z 中心平移到世界原点。
3. 把包围盒最低 Y 对齐到整理后平台顶面。

当前模型原始世界尺寸约为 `0.548 × 0.928 × 0.771`，预期缩放后高度约为 2.41 格；这些测量值仅用于验收，不作为实现常量。若模型缺失、没有有效网格或包围盒尺寸无效，组件记录包含资源名的错误并停用整个地标功能，世界其余部分继续运行。

## 2×2 地形平台

地标占用四列方块：`(-1, -1)`、`(-1, 0)`、`(0, -1)`、`(0, 0)`。组件等待四列所在区块均已生成且能够返回有效地表高度；等待期间不以默认高度放置模型。

平台目标高度取四列原始地表高度的中位值。若偶数样本的中间两个值不同，则取二者平均值向下取整，使平台高度始终为整数。平台调整遵循以下规则：

- 高于目标高度的方块被移除至目标高度。
- 低于目标高度的列使用原点列的原始地表方块类型补齐。
- 四列目标高度上方的树干、树叶和植物被清除，确保模型不与植被穿插。
- 调整通过 `ChunkManager` 的世界坐标方块 API 执行，使数据层、渲染层和现有持久化机制保持一致。
- 再次执行时，已经满足目标形态的平台不产生额外修改；世界重置后则针对新地形重新计算并放置。

旱厕是固定场景模型，不加入方块射线目标，也不能被挖掘。本期不为模型增加实体碰撞。

## 蜗牛生成与渲染

地标完成后，`SnailManager` 使用项目已有的确定性 RNG 生成 12 个位置和初始朝向。出生位置位于以旱厕中心为圆心、半径 3–10 格的环带内，并避开 2×2 底座。相同世界种子产生相同布局。

每只蜗牛约 0.7–0.9 格长，最高约 0.45 格。造型和动画以用户提供的体素蜗牛参考为基础，包含：

- 像素化身体、深浅身体、眼睛、壳体和深色壳体材质；
- 分段腹足波动；
- 触角摆动；
- 头部轻微转向；
- 壳体摇摆。

体素不得以每个小方块一个独立 draw call 的方式构建。静态属于同一动画部件的方块合并为共享几何体，并尽量使用单一支持顶点颜色的像素材质。12 只蜗牛共享几何体和材质，每只只维护自己的场景节点、部件变换和状态。

## 游走和地形跟随

正常状态下，蜗牛在各自当前朝向上缓慢前进，并以低频确定性扰动改变方向。移动遵循以下限制：

- 当前位置持续通过 `getTopSolidYWorld()` 采样地表，使蜗牛底面贴地。
- 下一步进入旱厕 2×2 底座、超出 3–10 格活动环带或目标列无地形数据时转向。
- 下一步地表与当前地表高度差大于 1 格时转向，不攀爬陡坎或跳下悬崖。
- 缩入、保持和展开期间停止平移，只播放缩壳状态动画。

本期蜗牛之间不做实体碰撞或群体避让；少量视觉重叠可以接受。

## 点击交互与状态机

蜗牛点击沿用游戏现有的锁定鼠标交互：玩家将屏幕中心准星对准蜗牛并按左键。`SnailManager` 使用独立 `THREE.Raycaster` 检测蜗牛可点击网格，并同时校验玩家到命中蜗牛的距离不超过 6 格。

左键事件按以下优先级处理：

1. 蜗牛管理器先检测近距离蜗牛命中。
2. 命中时将输入事件标记为已处理，并触发该蜗牛缩壳。
3. 方块挖掘控制器遇到已处理事件时直接返回，防止同一次点击开始挖掘蜗牛后方方块。
4. 未命中蜗牛时不标记事件，原有挖掘流程完全照常执行。

为保证同步事件顺序，`World` 在创建方块挖掘控制器前创建蜗牛管理器。蜗牛状态机为：

`CRAWLING → RETRACTING → RETRACTED → EMERGING → CRAWLING`

缩入动画按触角、头部、身体的顺序分段完成，展开时反向播放。一次完整受惊周期约 3 秒，包含缩入、保持和展开；具体分段时长集中在配置中。非 `CRAWLING` 状态下的重复点击不重启动画或延长计时。

## 生命周期和重置

首次初始化时，地标在 `update()` 中等待地形数据，成功后停止轮询并通知蜗牛管理器生成。世界重置会使地标和蜗牛系统回到等待状态；旧模型与蜗牛先从场景移除，新地形可用后重新计算平台、放置模型并按新世界种子生成蜗牛。

销毁顺序为蜗牛实例、蜗牛管理器共享资源、旱厕克隆模型和事件监听器。旱厕克隆体可以释放自身克隆的材质，但不得释放资源加载器持有的原始模型、共享纹理或其他组件仍在使用的资源。

## 配置

地标和蜗牛的稳定参数集中在专用配置模块，至少包括：

- 地标中心 `(0, 0)`；
- 2×2 脚印坐标；
- 旱厕目标底边 2 格；
- 蜗牛数量 12；
- 活动半径 3–10 格；
- 点击距离 6 格；
- 蜗牛目标长度范围 0.7–0.9 格；
- 游走速度、转向参数、最大可通过高度差和状态机分段时长。

Tweakpane 调试面板可暴露运动与动画连续参数，但功能不依赖调试模式，且不得新增 UI 层控件。

## 测试与验收

新增 Node 单元测试覆盖以下纯逻辑或隔离行为：

- 任意有效包围盒均按最长 X/Z 底边等比适配到 2 格，缩放后中心和底面偏移正确；无效包围盒被拒绝。
- 四列高度的整数中位值、平台补齐/削平计划以及重复执行的幂等性。
- 12 个确定性生成点均处于 3–10 格环带并避开 2×2 底座。
- 正常爬行、缩入、保持、展开和恢复爬行的状态转换，重复点击不重置计时。
- 命中蜗牛时左键被消费，未命中时事件保持未处理，方块挖掘行为不回归。

完成实现后执行：

```bash
node --test tests/unit/<新增测试文件>.unit.js
pnpm lint
pnpm build
```

浏览器验收包括：

1. 旱厕位于世界原点，底座覆盖且贴合平整的 2×2 平台，没有明显悬空、穿地或植被穿插。
2. 旱厕最长底边为 2 格，模型保持正确比例和朝向。
3. 旱厕周围可见 12 只约 0.7–0.9 格长的蜗牛，能够贴地游走且不进入底座。
4. 玩家在 6 格内准星左键命中蜗牛时，蜗牛缩壳，约 3 秒后恢复；后方方块不开始挖掘。
5. 未命中蜗牛的左键挖掘、右键放置、世界重置和现有 UI 均保持原行为。

## 非目标

- 蜗牛被旱厕真正“吃掉”、消失、掉落物品或进入旱厕模型内部；本期“旱厕吃蜗牛”以旱厕周边生态和点击缩壳交互呈现。
- 蜗牛生命值、伤害、捕捉、繁殖、存档或网络同步。
- 旱厕内部交互、动画、音效、粒子、碰撞或可破坏性。
- 跨 GPU 厂商的专项性能认证；本期仅进行共享资源、draw call 控制和常规浏览器验证。
